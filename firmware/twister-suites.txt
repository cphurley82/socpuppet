# What firmware/twister.py --suites runs: Zephyr's own suites on every
# board, which is the board-compliance run, and then socpuppet's own, each
# on the boards it names. A line is a directory to look for suites in, and
# then any flags that one suite needs. The directory is in Zephyr's tree,
# unless it is firmware or python, or under one of them: those are this
# repository's. The suites with no
# flags are run together, in one run of twister; a suite with flags gets a
# run of its own.
#
# -K (--force-platform) runs a suite on a board its own list of platforms
# leaves out. Zephyr's samples and its RISC-V fatal-error test name the
# boards they are for, and ours are not among them.
#
# What is left out of a suite, and why, is in firmware/twister-quarantine.yaml.
